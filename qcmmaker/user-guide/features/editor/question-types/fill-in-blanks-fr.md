# Texte à trous

Utilisez ce type lorsque le participant doit compléter les parties manquantes d'une phrase, d'une formule ou d'un énoncé structuré.

## Dans l'éditeur

Chaque réponse représente la valeur attendue d'un trou. Le texte environnant doit permettre de comprendre où placer chaque valeur.

Le panneau général expose la sensibilité à la casse. Une ligne peut aussi définir son mode d'évaluation et un indice. Une image ou un son peut être ajouté lorsqu'un trou nécessite son propre support.

## Indices

Ouvrez les options de la ligne pour ajouter un indice. Lorsqu'il existe, le menu permet de le modifier ou le supprimer. L'indice doit guider sans révéler directement la valeur.

## Validation

Chaque trou doit avoir une valeur attendue. Vérifiez ensemble le texte et les réponses : une valeur sans trou correspondant ou un trou sans valeur rend l'exercice incomplet.
