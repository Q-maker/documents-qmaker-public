# Jumbled words

Use Jumbled words when the learner must reconstruct one reference sentence from words or meaningful fragments.

## In the editor

Enter the words or fragments in the correct reference order. During play, QcmMaker presents them for rearrangement.

The question-level options sheet states that no additional options are available. Keep the proposition content textual: a media action may still be visible in the row menu, but unsupported proposition media can be rejected during validation.

## Authoring advice

- Split the sentence into fragments that can be manipulated comfortably.
- Avoid repeated identical words when their positions would be impossible to distinguish.
- Check punctuation and capitalization in the final reference sentence.
- State whether contractions or alternate word order should be considered.

## Validation

Complete the full reference sentence before moving forward. Test the question to confirm that the intended order is clear and achievable.
