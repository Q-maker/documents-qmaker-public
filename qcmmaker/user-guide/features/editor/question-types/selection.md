# Selection

Use Selection when the learner must recognize one or more correct answers among plausible choices.

## In the editor

![Completed selection question](../assets/selection-filled.png)

Each full-width row is one choice. Check every correct choice and leave distractors unchecked. Use the left handle to reorder a choice and **X** to remove it.

## Empty state

![Empty selection answer section](../assets/selection-empty.png)

Fill the first row, tap **Add an answer**, and add at least one more choice. A single filled row can be interpreted as a typed answer, so use at least two choices when recognition is intended.

## Options

The question-level sheet can control case sensitivity, input help, randomization, and eligible display limits. Row options can attach picture or audio media to an individual choice.

## Validation

![Selection without a checked correct answer](../assets/selection-validation-error.png)

With two or more filled choices, at least one must be checked as true. Review every checkbox before moving forward.
