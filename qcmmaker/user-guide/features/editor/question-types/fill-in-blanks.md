# Fill in the blanks

Use Fill in the blanks when the learner must complete missing parts of a sentence, formula, or structured statement.

## In the editor

Each answer entry represents the expected value of a blank. Keep the surrounding question text clear enough to show where every value belongs.

The question-level sheet exposes case sensitivity. A row can also define its text evaluation and an optional clue. Picture and audio actions are available when a blank needs its own supporting media.

## Clues

Open the row options to add a clue. Once a clue exists, the menu offers edit and delete actions. A clue should guide recall without directly revealing the expected value.

## Validation

Every blank must have an expected value. Review the question text and answer entries together: an extra value without a corresponding blank, or an unconfigured blank, makes the exercise unclear or incomplete.
