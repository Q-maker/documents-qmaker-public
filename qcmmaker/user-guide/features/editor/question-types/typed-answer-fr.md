# Réponse à saisir

Utilisez ce type lorsque se rappeler la réponse compte davantage que la reconnaître dans une liste.

## Dans l'éditeur

Chaque ligne pleine largeur est un texte accepté. Ajoutez des variantes d'orthographe ou de formulation uniquement si chacune doit être considérée comme correcte.

Le menu d'une ligne définit la comparaison :

- **Equal / Égalité :** correspondance avec la valeur attendue.
- **Contains / Contient :** le texte saisi doit contenir la valeur.
- **Pattern match / Motif :** utilisation du comportement de motif configuré.

Les options générales gèrent la casse et l'aide à la saisie. Les médias de proposition ne sont pas affichés, car ces lignes définissent une évaluation textuelle.

## Validation

Saisissez au moins une réponse acceptée pertinente. Évitez les variantes trop larges qui pourraient valider une réponse incorrecte.
