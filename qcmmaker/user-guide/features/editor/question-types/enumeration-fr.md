# Énumération

Utilisez l'énumération lorsque le participant doit fournir plusieurs éléments séparés plutôt qu'une seule phrase.

## Dans l'éditeur

Chaque ligne pleine largeur est un élément attendu. Saisissez-les séparément afin que QcmMaker puisse les évaluer selon la variante d'énumération choisie.

Le panneau général partage la famille des réponses textuelles : casse et aide à la saisie. Chaque ligne peut employer égalité, contenu ou motif. Les médias de proposition ne sont pas proposés.

## Conseil de rédaction

Indiquez dans l'énoncé combien d'éléments sont attendus, surtout lorsque d'autres réponses valides pourraient exister. Limitez chaque ligne à un seul élément sémantique.

## Validation

Ne laissez pas un ensemble partiellement rempli. Vérifiez que les éléments sont distincts et que leur règle d'évaluation n'accepte pas accidentellement un autre élément.
