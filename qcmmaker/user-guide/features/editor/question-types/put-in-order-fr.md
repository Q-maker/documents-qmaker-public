# Mise en ordre

Utilisez ce type pour restaurer une séquence : étapes d'une procédure, événements chronologiques, valeurs ou phases d'un processus.

## Dans l'éditeur

Chaque ligne pleine largeur est un élément. Saisissez-les dans le bon ordre de référence et utilisez les poignées pour le corriger avant l'enregistrement.

Le panneau général indique explicitement qu'aucune option supplémentaire n'est disponible. Les options de ligne peuvent ajouter une image ou un son compatible à un élément.

## Validation

![Mise en ordre avec trop peu d'éléments](../assets/order-validation-error.png)

Saisissez au moins deux éléments remplis. Une séquence vide ou partielle ne peut pas être validée.

## Conseil

Utilisez des éléments ayant une position non ambiguë. Si plusieurs ordres peuvent être corrects, reformulez l'énoncé ou précisez la règle de classement.
