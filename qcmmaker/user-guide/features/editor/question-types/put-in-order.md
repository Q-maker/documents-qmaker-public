# Put in order

Use Put in order when the learner must restore a sequence: procedure steps, chronological events, values, or stages of a process.

## In the editor

Each full-width row is one item. Enter the items in the correct reference order. Use the left handles to adjust that order before saving.

The question-level three-dot sheet explicitly reports that this type has no additional options. Row options can attach supported picture or audio media to an item.

## Validation

![Put-in-order question with too few items](../assets/order-validation-error.png)

Enter at least two filled items. Empty or partially authored sequences cannot be validated.

## Authoring advice

Use items with one unambiguous position. If several sequences could reasonably be correct, rewrite the question or explain the ordering rule in the prompt.
