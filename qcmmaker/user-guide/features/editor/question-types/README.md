# Choose a question type

Choose a type from what the learner must do, not only from how the answer looks in the editor. Changing the type changes the meaning of every answer row, the available options, and the validation rules.

| Learning task | Recommended type | Minimum valid content |
|---|---|---|
| Recognize one or more correct choices | [Selection](selection.md) | Two choices and at least one checked answer |
| Recall and type a short answer | [Type answer](typed-answer.md) | One accepted answer |
| Recall several separate items | [Enumeration](enumeration.md) | The expected items |
| Complete a sentence or expression | [Fill in the blanks](fill-in-blanks.md) | A value for every blank |
| Connect related concepts | [Match columns](match-columns.md) | At least two complete left/right pairs |
| Restore a sequence or procedure | [Put in order](put-in-order.md) | At least two items in reference order |
| Reconstruct a sentence from fragments | [Jumbled words](jumbled-words.md) | The complete ordered sentence or fragments |

## Shared authoring rule

The instruction immediately above the answer card is the contract for the active type. Read it after changing type and again if it turns red. The same row can represent a choice, accepted answer, blank value, pair cell, or ordered fragment depending on that contract.
