# Choose a question type

Choose a type from what the learner must do, not only from how the answer looks in the editor. Changing the type changes the meaning of every answer row, the available options, and the validation rules.

| Icon | Learning task | Recommended type | Minimum valid content |
|---|---|---|---|
| <img src="assets/icons/selection.png" alt="Selection icon" width="40" /> | Recognize one or more correct choices | [Selection](selection.md) | Two choices and at least one checked answer |
| <img src="assets/icons/typed-answer.png" alt="Type answer icon" width="40" /> | Recall and type a short answer | [Type answer](typed-answer.md) | One accepted answer |
| <img src="assets/icons/enumeration.png" alt="Enumeration icon" width="40" /> | Recall several separate items | [Enumeration](enumeration.md) | The expected items |
| <img src="assets/icons/fill-in-the-blanks.png" alt="Fill in the blanks icon" width="40" /> | Complete a sentence or expression | [Fill in the blanks](fill-in-blanks.md) | A value for every blank |
| <img src="assets/icons/match-columns.png" alt="Match columns icon" width="40" /> | Connect related concepts | [Match columns](match-columns.md) | At least two complete left/right pairs |
| <img src="assets/icons/put-in-order.png" alt="Put in order icon" width="40" /> | Restore a sequence or procedure | [Put in order](put-in-order.md) | At least two items in reference order |
| <img src="assets/icons/jumbled-words.png" alt="Jumbled words icon" width="40" /> | Reconstruct a sentence from fragments | [Jumbled words](jumbled-words.md) | The complete ordered sentence or fragments |

## Shared authoring rule

The instruction immediately above the answer card is the contract for the active type. Read it after changing type and again if it turns red. The same row can represent a choice, accepted answer, blank value, pair cell, or ordered fragment depending on that contract.
