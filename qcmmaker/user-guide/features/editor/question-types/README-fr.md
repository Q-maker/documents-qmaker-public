# Choisir un type de question

Choisissez le type selon l'action attendue du participant, pas seulement selon l'apparence de la réponse. Le type change la signification des lignes, les options disponibles et les règles de validation.

| Objectif | Type conseillé | Contenu minimal valide |
|---|---|---|
| Reconnaître une ou plusieurs bonnes réponses | [Sélection](selection-fr.md) | Deux choix et au moins une réponse cochée |
| Se rappeler et saisir une réponse courte | [Réponse à saisir](typed-answer-fr.md) | Une réponse acceptée |
| Donner plusieurs éléments séparés | [Énumération](enumeration-fr.md) | Les éléments attendus |
| Compléter une phrase ou une expression | [Texte à trous](fill-in-blanks-fr.md) | Une valeur pour chaque trou |
| Relier des concepts | [Association de colonnes](match-columns-fr.md) | Au moins deux paires gauche/droite complètes |
| Restaurer une séquence | [Mise en ordre](put-in-order-fr.md) | Au moins deux éléments dans l'ordre de référence |
| Reconstruire une phrase | [Mots mélangés](jumbled-words-fr.md) | La phrase ou les fragments dans l'ordre de référence |

## Règle commune

La consigne située juste au-dessus de la carte de réponses constitue le contrat du type actif. Relisez-la après un changement de type et lorsqu'elle devient rouge. Une ligne peut être un choix, une réponse acceptée, une valeur de trou, une cellule de paire ou un fragment ordonné.
