# Choisir un type de question

Choisissez le type selon l'action attendue du participant, pas seulement selon l'apparence de la réponse. Le type change la signification des lignes, les options disponibles et les règles de validation.

| Icône | Objectif | Type conseillé | Contenu minimal valide |
|---|---|---|---|
| <img src="assets/icons/selection.png" alt="Icône Sélection" width="40" /> | Reconnaître une ou plusieurs bonnes réponses | [Sélection](selection-fr.md) | Deux choix et au moins une réponse cochée |
| <img src="assets/icons/typed-answer.png" alt="Icône Réponse à saisir" width="40" /> | Se rappeler et saisir une réponse courte | [Réponse à saisir](typed-answer-fr.md) | Une réponse acceptée |
| <img src="assets/icons/enumeration.png" alt="Icône Énumération" width="40" /> | Donner plusieurs éléments séparés | [Énumération](enumeration-fr.md) | Les éléments attendus |
| <img src="assets/icons/fill-in-the-blanks.png" alt="Icône Texte à trous" width="40" /> | Compléter une phrase ou une expression | [Texte à trous](fill-in-blanks-fr.md) | Une valeur pour chaque trou |
| <img src="assets/icons/match-columns.png" alt="Icône Association de colonnes" width="40" /> | Relier des concepts | [Association de colonnes](match-columns-fr.md) | Au moins deux paires gauche/droite complètes |
| <img src="assets/icons/put-in-order.png" alt="Icône Mise en ordre" width="40" /> | Restaurer une séquence | [Mise en ordre](put-in-order-fr.md) | Au moins deux éléments dans l'ordre de référence |
| <img src="assets/icons/jumbled-words.png" alt="Icône Mots mélangés" width="40" /> | Reconstruire une phrase | [Mots mélangés](jumbled-words-fr.md) | La phrase ou les fragments dans l'ordre de référence |

## Règle commune

La consigne située juste au-dessus de la carte de réponses constitue le contrat du type actif. Relisez-la après un changement de type et lorsqu'elle devient rouge. Une ligne peut être un choix, une réponse acceptée, une valeur de trou, une cellule de paire ou un fragment ordonné.
