# Enumeration

Use Enumeration when the learner must provide several separate items rather than one sentence.

## In the editor

Each full-width row is one expected item. Enter the items independently so QcmMaker can evaluate them separately according to the chosen enumeration variant.

The question-level sheet shares the text-answer family: case sensitivity and input assistance are available. Each row can use equality, contains, or pattern evaluation. Proposition pictures and audio are not offered.

## Authoring advice

State how many items are expected in the question, especially when the learner may know more valid examples than the quiz contains. Keep each row limited to one semantic item.

## Validation

Do not leave a partially filled expected-answer set. Check that every item is distinct and that the selected evaluation rule cannot accidentally match another item.
