# Match columns

Use Match columns when the learner must connect related items, such as a country and its capital, a term and its definition, or an event and its date.

## The editor uses a two-column grid

Unlike the other question types, Match columns is not displayed as one full-width answer list. Each visual row is one semantic pair: the item in column A belongs with the item in column B on the same row.

![Completed Match columns grid from the English Demo quiz](../assets/match-column-grid.png)

| Visual row | Column A | Column B |
|---|---|---|
| Pair 1 | USA | Washington DC |
| Pair 2 | France | Paris |
| Pair 3 | Cameroon | Yaoundé |

## Add, edit, and remove pairs

- **Add an answer** creates a new A/B pair, not one independent list item.
- Edit both cells in the row before moving forward.
- The remove action deletes the complete pair.
- The options area of each cell can manage media belonging to that cell.

Do not think of the columns as two unrelated lists. The authored row is the correction reference even if the player later shuffles one or both columns.

## Question options

![Match-column randomization options](../assets/options-sheet-match-column.png)

The question-level sheet can randomize the left column, the right column, or both. This changes presentation during play without changing the stored matches.

## Validation

Create at least two complete matches. A row with only column A or column B filled is incomplete and must be completed or removed.
