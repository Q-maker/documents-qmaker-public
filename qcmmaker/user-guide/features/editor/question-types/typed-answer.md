# Type answer

Use Type answer when remembering the answer matters more than recognizing it in a list.

## In the editor

Each full-width row is an accepted text answer. Add spelling or wording variants only when each variant should receive credit.

The option menu for a row defines how QcmMaker evaluates typed text:

- **Equal:** the answer must match the expected value.
- **Contains:** the learner's text must contain the expected value.
- **Pattern match:** the answer is evaluated using the configured pattern behavior.

Question-level options control case sensitivity and supported input assistance. Proposition picture and audio actions are not shown because these rows define text evaluation.

## Validation

Enter at least one meaningful accepted answer. Avoid adding overly broad variants that could accept an incorrect response.
