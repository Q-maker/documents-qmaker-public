# Partager un quiz

Le mode de partage natif de QcmMaker repose sur le fichier : vous envoyez directement le fichier de quiz portable `.qcm`. Le destinataire reçoit une copie complète qu'il peut conserver, déplacer, sauvegarder et ouvrir avec un lecteur QCM compatible.

Le partage d'un quiz hébergé au moyen d'un lien HTTP est une possibilité supplémentaire et distincte. Un lien est une adresse qui pointe vers un quiz distant ; il ne constitue pas le fichier `.qcm` lui-même.

## Partager le fichier `.qcm` — méthode native

Choisissez cette méthode lorsque vous souhaitez que le destinataire reçoive le fichier de quiz et conserve une copie locale sous son contrôle.

→ [Partager un quiz sous forme de fichier `.qcm`](share-a-qcm-file-fr.md)

Si vous avez reçu un fichier `.qcm` et souhaitez l'ouvrir, consultez [Lire un fichier `.qcm` partagé](read-a-shared-qcm-file-fr.md).

## Partager un quiz hébergé par lien — méthode supplémentaire

Choisissez cette méthode lorsque votre fichier `.qcm` est déjà hébergé en ligne, ou lorsque vous souhaitez l'héberger afin que d'autres personnes accèdent au quiz distant au moyen d'une adresse HTTP.

→ [Partager et ouvrir des liens vers des quiz hébergés](open-quiz-links-fr.md)
