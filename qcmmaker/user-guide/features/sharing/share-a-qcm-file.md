# Share a Quiz as a `.qcm` File

The native way to share a quiz with QcmMaker is to send the `.qcm` file itself. This file is the quiz: it can carry its questions, answers, settings, correction information, pictures, and sounds in one portable package.

You can send it through email, a messaging app, Bluetooth, nearby sharing, removable storage, a cloud drive, or any other service capable of transporting a file. The transport method does not need to understand the quiz.

## Why Share the File Itself?

| Benefit | What it means for you and the receiver |
|---------|----------------------------------------|
| Portable quiz | The quiz and its embedded content travel together in one `.qcm` file. |
| Control of your copy | You decide where your file is stored, which copies you keep, and who receives one. |
| Decentralized sharing | No particular quiz catalog or central sharing service is required to transport the file. |
| Local and offline use | Once the file and a compatible reader are available on the device, the quiz's local content can be opened without depending on the original sharing channel. Some protected or remote features may still require a connection. |
| Easy backup | The file can be copied to another folder, drive, device, or backup system like other documents. |
| Reader compatibility | Any application that correctly supports the `.qcm` format can open compatible quiz content. |

The receiver obtains an actual copy of the quiz rather than only an address pointing to a remote location. If the email, message, or transfer service is no longer available later, the saved copy of the file remains under the receiver's control.

## Before Sharing

Open and play the quiz once to verify its questions, answers, correction, pictures, and sounds. Sharing sends the saved `.qcm` file; it does not apply unsaved editor changes after the file has already been sent.

If your author profile is empty, QcmMaker warns that the shared file may identify its author as anonymous.

![Author warning](images/share-author-warning.png)

Fill in your author profile before sharing when you want the quiz file to carry your signature.

## Share From QcmMaker

1. Open the quiz detail page or project page.
2. Choose the **Share** action.
3. Read and confirm the reminder about compatible QCM readers.

![Share warning](images/share-qcm-warning.png)

4. Choose the email, messaging, storage, or file-transfer application from Android's share sheet.

![Android share sheet](images/android-share-sheet-qcm.png)

QcmMaker sends the `.qcm` file through the application you selected. The original file in your workspace remains in place.

## Share From a File Manager

You can also locate an existing `.qcm` file with your device's file manager and use Android's standard Share action. This sends the same kind of portable quiz file as the Share action inside QcmMaker.

## Help the Receiver Open It

Tell the receiver that the attachment is a `.qcm` quiz file and that it opens with a compatible QCM reader. They can use QcmMaker on Android or select the local file from a browser on [read.qcmfile.com](https://read.qcmfile.com).

→ Send them [Read a shared `.qcm` file](read-a-shared-qcm-file.md) when they need installation links or opening instructions.

## Prefer to Share an HTTP Address?

If the `.qcm` file is already hosted online, or if you want to host it and distribute an address instead of sending a copy of the file, see [Share and open hosted quiz links](open-quiz-links.md).
