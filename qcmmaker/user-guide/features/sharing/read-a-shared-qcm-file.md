# Read a Shared `.qcm` File

A `.qcm` file is a portable quiz document. It can carry questions, answers, settings, correction information, pictures, and sounds so that the complete quiz can be sent by email, messaging apps, cloud storage, or any other file-sharing method.

## Why You Need a Compatible Reader

Sharing a quiz does not convert it into a live classroom session or an ordinary document. The file must be interpreted by software that understands the `.qcm` format.

| File received | Compatible software |
|---------------|---------------------|
| `.pdf` document | A PDF reader |
| `.docx` document | A compatible word processor |
| `.qcm` quiz | QcmMaker or another compatible QCM reader |

The reader does not have to be an installed Android app. QmakerTech also provides a browser-based reader.

## Open a Local `.qcm` File in a Browser

1. Download or save the received `.qcm` file on your device.
2. Open [read.qcmfile.com](https://read.qcmfile.com) in a browser.
3. Use the local-file selector and choose the `.qcm` file.
4. Wait for the reader to open the quiz, then preview or play it using the available options.

This method is useful when you do not want to install an Android application. Selecting a local file is different from opening a hosted quiz link: you do not need to upload or host the file first.

## Open the File With QcmMaker on Android

1. Install or update a compatible QcmMaker edition.
2. Tap the `.qcm` attachment or downloaded file.
3. If Android asks which app to use, choose QcmMaker.

You can also open QcmMaker and use its file-opening option to select a `.qcm` file stored on your device.

## If You Received a Quiz Link

A compatible link can open a remotely hosted quiz in QcmMaker or in the web reader. This is different from receiving the `.qcm` file itself.

See [Open shared quiz links](open-quiz-links.md) for supported link types and play modes.

## Before You Send a Quiz

- Open and play the quiz once to check its questions, answers, correction, pictures, and sounds.
- Send the `.qcm` file using QcmMaker's Share action or your device's file manager.
- Tell the receiver that the file requires a compatible reader and share this page when helpful.

Sharing creates or sends another occurrence of the quiz file. It does not change the original `.qcm` file stored in your workspace.

## Troubleshooting

- **No app opens the file:** install or update QcmMaker, or select the file on [read.qcmfile.com](https://read.qcmfile.com).
- **The file is not visible in the browser selector:** check that it finished downloading and still has the `.qcm` extension.
- **A quiz link does not open:** confirm that the full link was copied and that the remote file is still accessible.
- **Some quiz content is not interpreted correctly:** update the reader and try opening the file again.
