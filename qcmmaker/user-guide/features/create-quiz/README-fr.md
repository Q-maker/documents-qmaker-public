# Créer et modifier un quiz

Un quiz QcmMaker est un fichier `.qcm` portable. La création du fichier n'est que la première étape : il faut aussi renseigner les informations, créer des questions valides, configurer la session et tester le résultat avant le partage.

## Choisir une tâche

| Objectif | Page conseillée |
|---|---|
| Créer un nouveau fichier | [Créer le quiz](create-quiz-fr.md) |
| Ajouter un titre, une couverture, un sujet, une description ou des réglages | [Modifier les informations](edit-information-fr.md) |
| Créer les questions et réponses | [Modifier les questions](../editor/README-fr.md) |
| Choisir le format adapté | [Guide des types](../editor/question-types/README-fr.md) |
| Ajouter images, sons ou explications | [Médias et commentaires](../editor/media-and-comments-fr.md) |
| Réordonner, naviguer, valider et enregistrer | [Organiser et enregistrer](../editor/organize-and-save-fr.md) |
| Tester le quiz | [Modes de jeu](../play-modes/README-fr.md) |
| Envoyer le quiz | [Partage](../sharing/README-fr.md) |

## Parcours recommandé

1. [Créez le fichier `.qcm`](create-quiz-fr.md).
2. [Décrivez et configurez le quiz](edit-information-fr.md).
3. [Ajoutez les questions](../editor/README-fr.md) avec le format adapté à chaque objectif.
4. Ajoutez un commentaire ou un média uniquement lorsqu'il facilite la compréhension.
5. Enregistrez et lancez le quiz dans le mode prévu.
6. Vérifiez les réponses, la correction, le temps et la notation avant le partage.

> Pour une première prise en main, suivez le tutoriel court [Créer son premier quiz](../../getting-started/first-quiz-fr.md).
