# Edit quiz information

**Goal:** explain what the quiz is about and define how a normal play session should behave.

**Starting point:** open a quiz, then choose **Edit information**. When a quiz has just been created, QcmMaker opens this screen automatically.

Quiz information has two purposes. Descriptive fields help people recognize and understand the quiz. Session settings control how many questions are used, how they are ordered, timed, corrected, and played.

## Describe the quiz

![Completed information from the English Demo quiz](images/project-information-filled.png)

Tap the pencil beside a row to edit it.

| Information | What it tells the learner | Practical advice |
|---|---|---|
| Cover picture | Visually identifies the quiz in the workspace and preview | Choose an image that remains recognizable at card size. |
| Title | Names the quiz | Use a specific title rather than a generic file name. |
| Topic | Groups the subject name, icon, and short explanation | State the domain being tested, such as geography or safety. |
| Knowledge level | Indicates the intended level or audience | Match it to the difficulty of the questions. |
| Description | Explains the purpose and content before play | Mention the goal, scope, and any useful instructions. |
| Scoring policy | Explains how answers earn points | Check that it matches questions with multiple correct answers. |

The quiz file name and the visible quiz title serve different purposes: the file name helps you find the `.qcm` file, while the title is part of the quiz content shown to learners.

## Configure a play session

Scroll below the descriptive information to reach the session settings.

![Session settings from the English Demo quiz](images/project-information-settings.png)

| Setting | Effect |
|---|---|
| Total questions | Shows the number of questions currently stored in the quiz. |
| Random mode | Changes the order in which questions can be selected or presented. |
| Questions per session | Limits a play session to part of the quiz. It cannot use more questions than the quiz contains. |
| Time per question | Sets the available answer time when the selected play mode uses timing. |
| Questionnaire language | Identifies the language of the quiz content. |
| Show correction | Controls whether the learner can see the correction after answering or finishing. |
| Smart input | Enables supported input assistance while the learner answers. |
| Lock editing | Protects the quiz from ordinary editing when enabled. |
| Supported play mode | Restricts the quiz to a compatible mode, or leaves QcmMaker to choose automatically. |

Not every setting changes every play mode. For example, a timing value matters only when the chosen mode uses a timer. After changing session settings, test the quiz in the mode your learners will use.
