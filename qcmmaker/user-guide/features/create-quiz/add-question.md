# Add a question

This page is the shortest route to a first valid question. For the complete editor reference, open [Edit questions](../editor/README.md).

1. From the quiz information screen, tap **EDIT QUESTIONS**.
2. Enter the prompt in the large question field.
3. Tap the type icon and choose how the learner must answer.
4. Fill the answer section according to the instruction above it.
5. Tap **Next** or **Save** to validate the page.

![Completed selection question](../editor/assets/selection-filled.png)

For a first Selection question, add at least two choices and check at least one correct answer. If the instruction turns red, complete the stated requirement before leaving the page.
