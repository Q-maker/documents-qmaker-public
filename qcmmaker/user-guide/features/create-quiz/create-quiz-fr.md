# Créer un quiz

> [Read this page in English](create-quiz.md).

**Objectif :** créer un fichier `.qcm` vide qui pourra être configuré et complété.

**Point de départ :** l'écran d'accueil de QcmMaker.

Un fichier `.qcm` contient les informations du quiz, ses questions, réponses, médias, commentaires de correction et réglages de lecture.

Ouvrez le menu d'actions de l'espace de travail, puis touchez **Create a new quiz project / Créer un nouveau projet**.

![Menu d'actions](../../getting-started/images/workspace-actions-menu.png)

L'icône d'aide explique que le nouveau projet sera enregistré dans un fichier `.qcm`.

![Aide à la création](../../getting-started/images/dialog-create-quiz-help.png)

Saisissez un nom et touchez **CREATE / CRÉER**.

![Dialogue de création](images/dialog-create-quiz.png)

Ce nom identifie le fichier dans l'espace de travail. Vous pourrez ensuite ajouter un titre et une description destinés aux participants.

## Résultat attendu

QcmMaker ouvre l'écran d'informations du nouveau quiz. Le fichier existe, mais son contenu n'est pas encore complet.

**Étape suivante :** [renseigner les informations et réglages](edit-information-fr.md), puis [créer les questions](../editor/README-fr.md).
