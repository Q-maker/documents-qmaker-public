# Ajouter une musique d'ambiance au quiz

Un quiz peut contenir un fond sonore joué en boucle pendant une session. Ce son appartient au quiz entier, contrairement à un audio attaché à une question, une proposition ou un commentaire de correction.

## Comment y accéder

Ouvrez un quiz → **Modifier les informations** → menu supplémentaire de la barre → **Plus d'options** → ligne de la musique d'ambiance à jouer en boucle pendant le test.

## Choisir le son

![Choix de la source du fond sonore, interface en anglais](assets-en/audio-source-menu.png)

1. Ouvrez la ligne du son d'ambiance.
2. Choisissez **Galerie** pour un fichier audio existant, **Enregistrer** pour un enregistrement, ou **Lien web** pour une ressource audio en ligne.
3. Terminez l'import ou l'enregistrement et accordez l'accès au fichier ou au microphone si nécessaire.
4. Vérifiez le son sélectionné, fermez les options, puis enregistrez le quiz.

Lorsqu'un son est déjà présent, rouvrez cette ligne pour consulter les actions d'écoute, de remplacement ou de suppression disponibles. Choisissez un fond sonore qui laisse les questions parlées et les réponses audio compréhensibles.

## Contrôler la lecture

Lancez le quiz pour vérifier le résultat. Dans **Préférences → Quiz et lecteur**, le réglage de lecture du son d'ambiance commande son démarrage automatique lorsqu'un quiz fournit une bande sonore.

L'ajout d'un fond sonore peut demander un accès premium. Choisissez un son que vous avez le droit de joindre si vous partagez le quiz. Cette option ajoute un son existant ou enregistré.
